# Backend: Credit Card Buddy API

This directory contains the backend scaffold for the app.

## Recommended stack

- Node.js + TypeScript
- Express or Fastify
- PostgreSQL
- Prisma or TypeORM

## API responsibilities

- User authentication
- Card/account management
- Transaction sync
- Reward estimation
- Provider connector management

## Next steps

1. Initialize the backend with `npm init -y`
2. Set up TypeScript
3. Add API routes for `/auth`, `/cards`, `/transactions`, `/providers`, and `/recommendations`
4. Create an adapter layer for Account Aggregator integrations
