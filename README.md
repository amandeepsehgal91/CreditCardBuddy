# Credit Card Buddy

A native iOS + iPadOS app for managing credit cards, tracking card rewards, and optimizing spend. This project is designed as an MVP for the Indian market, with architecture built to scale to the US market later.

## Stack

- Mobile: SwiftUI + Swift
- Architecture: MVVM
- Backend: Node.js + TypeScript
- Database: PostgreSQL
- Integration Layer: Account Aggregator adapter pattern

## Structure

- `mobile/` — iOS app design and starter code
- `backend/` — API backend scaffold
- `docs/` — architecture and product design

## Next step

Open this folder in Xcode or VS Code to continue building the app. The first screen is the Home Dashboard with card overview, spend summary, and quick actions.
